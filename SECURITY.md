# Security Policy

## Supported Versions
We currently provide security updates for the following versions:

| Version | Supported |
|---------|-----------|
| Latest  | ✅ |
| Older Versions | ❌ |

Please update to the latest version to receive security patches.

## Reporting a Vulnerability
If you discover a security vulnerability, please follow these steps:

1. **Do NOT create a public issue.** Security issues should be reported privately to prevent exploitation.
2. Contact the maintainers at **SECURITYPR@furkanhuman.app** with details of the vulnerability.
3. Include:
   - A detailed description of the issue.
   - Steps to reproduce it (if applicable).
   - Possible fixes or suggestions.

We will investigate the issue and respond as soon as possible. Thank you for helping keep the project secure! 🔒

## Security Best Practices
To maintain security when contributing:
- Never expose sensitive data (API keys, passwords, or personal information) in commits.
- Use strong authentication and secure communication when interacting with the repository.

## Responsible Disclosure
We follow a **responsible disclosure policy**. If you report a security vulnerability responsibly, we will credit your contribution and work with you to resolve the issue swiftly.

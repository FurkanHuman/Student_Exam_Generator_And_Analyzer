# Summary of the Petition to Edirne Provincial Directorate of National Education  

**Date:** 12/09/2025  
**Recipient:** Edirne İl Millî Eğitim Müdürlüğü (Provincial Directorate of National Education – Edirne)  
**Subject:** Request for Access to Data, Technical Documentation, and Appointment for the *Student Exam Generator and Analyzer System (S.E.S.)* Project  

---

## Purpose of the Project  
- The **S.E.S. Project** aims to improve school exam processes by making them:  
  - **Secure**  
  - **Transparent**  
  - **Data-driven**  
- Designed to operate **locally per school**, ensuring:  
  - **Data minimization**  
  - **Anonymization**  
  - **Compliance with KVKK (Personal Data Protection Law of Türkiye)**  

---

## Requests Made  
1. **Access to Student and Teacher Data**  
   - Student data: name-surname, class, gender  
   - Teacher data: name-surname, subject branch, class relations, course relations  
   - Data usage: strictly limited to the project, anonymized, and protected under KVKK.  

2. **Access to Technical Documentation**  
   - School management system structures  
   - API specifications  
   - Data dictionaries  
   - Example data formats  

3. **Contact Information**  
   - Details of authorized/technical contacts for coordination on data access and technical processes.  

---

## Additional Points  
- Request for an **official meeting** (in-person or online) to discuss:  
  - Technical details  
  - Data security  
  - Needs analysis  
- Commitment that:  
  - Data will only be used in **anonymized and aggregated form**  
  - Any analytical or machine-based models will remain limited to this scope  
  - Personal data will be protected per KVKK and Ministry of Education regulations  
  - No data will be shared with third parties
